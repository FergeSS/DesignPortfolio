Подключение к Диску

Админка сможет изменять только папку этого портфолио. Ключ не отправляется в GitHub и не попадает на публичный сайт.

Где получить токен
  1. Создай своё приложение в Яндекс OAuth ↗ с правами «Чтение всего Диска» и «Запись в любом месте на Диске».
  2. Для получения токена вручную используй Redirect URI https://oauth.yandex.ru/verification_code.
  3. Открой https://oauth.yandex.ru/authorize?response_type=token&client_id=ТВОЙ_CLIENT_ID, разреши доступ и вставь полученный токен в поле выше.

Не присылай токен в чат. Несмотря на права токена, админка проверяет публичную ссылку и ограничивает операции папкой портфолио.
